# Sistema Reflexión — pipeline de series narradas

Producción de series de 5 capítulos (≈4 min, 9:16) con voz Fish Audio, imágenes y clips de G-Labs, subtítulos CapCut, hook de 10 s, miniaturas y entrega a Google Drive.

| Carpeta | Qué contiene |
|---|---|
| `PLAYBOOK.md` | El método paso a paso, con comandos y trampas |
| `CLAUDE.md` | Instrucciones para que un Claude nuevo trabaje igual |
| `contexto/` | Master prompt (reglas del guion), SISTEMA_DE_PRODUCCION, contexto de la serie |
| `reglas/` | Preferencias de Luis aprendidas (una por archivo) y estado de cada lote |
| `src_serie/` | Scripts de una serie (copiar a `<serie>\src`) |
| `orquestacion/` | Scripts que encadenan audio, producción, hooks y montaje de una serie completa |
| `ayudantes/` | Herramientas para escribir y revisar el paquete visual |
| `ejemplo_serie_carniceria/` | Textos reales de una serie terminada como modelo de formato |
| `fonts/` | Fuentes libres (Montserrat, Baloo 2). Georgia se toma de `C:\Windows\Fonts` |

No contiene claves, audio, imágenes ni videos (ver `.gitignore`). Se recomienda repositorio **privado**: incluye guiones y reglas del negocio.
